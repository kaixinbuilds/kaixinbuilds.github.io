Lino prints (dottyprints) used on the site.

MASTERS ARE KEPT HERE. Do not put source art loose in the repo root: filenames
on macOS are case-insensitive, so a file named Favicon.png and a generated
favicon.png are the same file, and one silently overwrites the other. Keep
originals in this folder under their own name.

  diskette-print.png        master, 1254px. Source for favicon.png and
                            apple-touch-icon.png in the repo root.
  payphone-print.png        the payphone block, shown on the approach page.
  payphone-background.jpg   the same payphone pattern recoloured to ink and
                            ochre, used as the fixed page background.

Regenerating the icons from the master is a crop to the ink, 14% padding, a
recolour to the site palette, then a downscale. Ask and it will be redone.

If you add a new print: export the artwork only, cropped to the paper edge,
around 1600px on the long side. Not an Instagram screenshot, which carries app
chrome, like counts and other people's profile pictures.

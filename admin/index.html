How to make a key

You do this once, then again whenever the key expires. GitHub emails you before that happens.

  1. Signed in to GitHub as kaixinbuilds, open new fine-grained token.
  2. Token name: kaixinbuilds editor. Expiration: up to a year.
  3. Repository access: Only select repositories, then pick kaixinbuilds.github.io.
  4. Permissions › Repository permissions › Contents: Read and write. Leave everything else alone.
  5. Generate the token, copy it, and paste it above. GitHub shows it only once. If you lose it, make a new one.

Anyone holding this key can change your site, so keep it to yourself. On a shared computer, leave Remember on this device unticked and the key is forgotten when the tab closes. If a device goes missing, delete the key on GitHub under Settings › Developer settings › Fine-grained tokens.
